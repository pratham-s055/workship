# The Workship Studio — static site

This folder is a plain HTML, CSS, and JavaScript version of the landing page. It has no build step or package dependencies.

## Preview locally

Open `index.html` in a browser, or run any basic static file server from this folder.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your branch and the **/docs** folder, then save.

GitHub Pages will publish this folder. The fonts load from Google Fonts when a visitor has internet access; system fonts are used as a fallback.
